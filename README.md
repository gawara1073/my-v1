# コマ合わせ 📅 | 大学生向け空き時間チェッカー v6.0 (プレゼン特化型)

7/10 の CHIBATECH PROTOTYPE 最終発表に向けた、**「一瞬で価値が伝わる」**プレゼンテーション特化バージョンです。

---

## 🚀 v6 での劇的アップデート！

1.  **3秒でわかるクイックガイド**
    - 画面上部になぞるだけの3ステップガイドを常設。初めて見る人も瞬時に使い方を理解できます。
2.  **ワンクリック・デモ機能 (プレゼン用)**
    - 「サンプルメンバーを追加」ボタン一つで、たろう・はなこ・じろうの3人分の予定を自動生成。一瞬でヒートマップが染まり、おすすめ時間が提案される様子をデモできます。
3.  **アクションの視覚的な強調**
    - AIによる「おすすめ時間帯」や「日程決定ボタン」にアニメーションとリッチなデザインを追加。次に何をすべきかが迷わず伝わります。
4.  **UI文言のブラッシュアップ**
    - 「メンバーに追加」を「予定を確定して保存」に変更するなど、ユーザーの心理に寄り添った表現に刷新しました。
5.  **モバイル・プレゼン対応**
    - 片手での操作性、ボタンの押しやすさを強化。発表中の実機デモもスムーズに行えます。

## 🌟 これまでの主要機能

-   **カレンダー日付選択**: 遊びたい日をカレンダーから最大10日まで自由選択。
-   **時限カスタマイズ**: 大学のコマ割り（1限〜10限）や時間を自由に変更＆テンプレート適用。
-   **スマートヒートマップ**: 全員の空き時間が重なるほど色が濃くなり、全員空き（100%）は王冠でお祝い。
-   **LINEダイレクト連携**: 調整した予定を1タップでLINEへ送信。
-   **完全サーバーレス**: 個人情報不要、URLだけでデータ共有が完結。

## 🎨 開発の想い

「コマ合わせ」は、LINEでの非生産的な『いつ空いてる？』の応酬をなくし、大学生の自由な時間を最大化するために生まれました。v6は、その価値をプレゼンテーションという限られた時間の中で最大限に伝えるための集大成です。
