# コマ合わせ 📅 | 大学生向け空き時間チェッカー v4

LINEでの面倒な予定調整を、タップだけで一瞬で解決する大学生向け予定調整ツール「コマ合わせ」の最新版 v4 です。
サーバー不要、DB不要。HTML/CSS/JavaScriptのみで動作する究極のサーバーレス設計。

---

## 🌟 v4でのパワーアップ要素（主な機能）

1. **カレンダーからの日付選択機能**
   - 月間カレンダーから候補日を自由に複数選択して調整できるようになりました。
2. **時限（コマ）の完全カスタマイズ（新登場！）**
   - 大学や予定に合わせて、「1限〜10限まで増やす」「開始時間を書き換える」といった設定が自由自在になりました。
   - 設定したコマ割りは共有URLに含まれるため、友達も同じ設定で入力できます。
3. **「おすすめ」表示の直感化！最優先候補がひと目でわかる**
   - メンバー追加時、最も参加人数の多い時間帯を「おすすめの時間帯 ✨」として強力にプッシュ。
   - デザインを刷新し、カラフルかつプレミアムなカード形式で一番いい時間を逃しません。
3. **ヒートマップの色分け改善（カラーコーディング）**
   - 参加人数の一致率を「緑・黄・赤」系統のカラーパレットで可視化。
   - 全員空いている時間は「👑 100%」として特別なエフェクトで表示。
3. **UI/UXの徹底改善！初めての人でも迷わない**
   - ステップごとの説明文をブラッシュアップし、大学生が直感的に操作できるように調整。
   - 入力フォームやボタンのアニメーションを強化し、心地よい操作感を実現。
4. **v3からのプレミアム機能も継承**
   - **ライト＆ダークモード**: OS設定連動＆手動切り替え対応。
   - **スクロールロック**: なぞり選択時の画面のブレを防ぐ。
   - **曜日スワイプ**: 指一本で月〜日までパタパタ切り替え。
   - **LINEダイレクト連携**: 1タップでLINEアプリを立ち上げて送信。

## 🚀 予定調整の流れ

1. **主催者が土台を作る**
   - 自分の名前を入力し、空いているコマを選んで「メンバーに追加」
   - 「共有URLをコピー」を押し、LINEグループに貼る。

2. **友達が予定を重ねる**
   - 送られてきたURLを開くと、すでに主催者の予定が入った状態でスタート。
   - 友達も自分の予定を入れて「メンバーに追加」。最新のURLをまたLINEに貼る。

3. **「おすすめ」で即決！**
   - メンバーが増えると、全員の空き時間を自動計算し「おすすめ」を表示。
   - 決定ボタンを押して、LINE送信用テキストをコピー＆ペーストで調整完了！

## 🎨 技術的な解説

- **完全サーバーレス**: すべてのデータはURL内のハッシュ（Base64/UTF-8）に保存されます。
- **バニラ JS/CSS**: フレームワークを一切使わず、ブラウザの標準機能だけで最高級のパフォーマンスを発揮します。
- **マルチデバイス対応**: PCでのドラッグ操作、スマホでのなぞり・スワイプ操作の両方に最適化されています。
